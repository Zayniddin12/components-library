# MacOs Usefull Informations

## WebStorm

You can easily close tabs in ide with `Shift + Mouse`


## Safari

### Opening developers tool

- Turn on from settings
`Safari -> Settings -> Advanced -> Turn on Developers menu in menu bar`

- For responsive mode open develop from menu bar click to responsive design mode or `⌃ + ⌘ + R`

## System

- You can switch windows with `⌃ + < or >`

- Switching language with `fn 🌐`
