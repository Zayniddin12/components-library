# Radio

Radio should not have too many options. Otherwise, use the Select component instead.

## Basic

<Story name="Base" id="components-radio--base-radio" />

```html
<SDropdown :list="items" v-model="value" name="name" />
```

## Disabled

`disabled` attribute is used to disable the radio.

You just need to add the `disabled` attribute.

<Story name="Disabled" id="components-radio--disabled" />

```html
<SDropdown :list="items" v-model="value" name="name" disabled />
```

## Radio Group

Suitable for choosing from some mutually exclusive options

You have to add required props as `name`, `labelKey`, `valueKey`. Value of `labelKey` and `valueKey` have to be the same with keys of `items` prop.

<Story name="Group" id="components-radio--group" />

```html
<!-- Tempate -->

<SDropdown
  :list="items"
  v-model="value"
  name="name"
  labelKey="name"
  valueKey="id"
/>
```

```js
// Script

const value = ref([]);
const items = ref([
  {
    id: 1,
    name: "Name",
  },
  {
    id: 2,
    name: "Surname",
  },
  {
    id: 3,
    name: "Birthdate",
  },
]);
```
