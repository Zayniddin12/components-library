# UIC Logo


## **Overview**

The UIC Logo component is a customizable component that can be used in a Vue.js application. It has 2 props that can be used to customize the appearance of the component.

## **Props**

The following props can be passed to this component:

| Props         | Description                                                                                               |
| ------------- | --------------------------------------------------------------------------------------------------------- |
| mainColor        | A string that sets the color of the main logo                                         |
| SecondaryColor    |A string that sets the color of the secondary logo                                                   |
