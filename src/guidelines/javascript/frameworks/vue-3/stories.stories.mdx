# Stories

A **Story** is a **Presentation** described in [Container/Presentational Pattern](https://www.patterns.dev/posts/presentational-container-pattern/).

It is a dummy entity that is included on the **[Storybook](https://storybook.js.org/)** page.

It should not handle any business logic.

It is a pure entity described in [Components and Props React Docs](https://reactjs.org/docs/components-and-props.html#props-are-read-only).

> Such functions are called [“pure”](https://en.wikipedia.org/wiki/Pure_function) because they do not attempt to change their inputs, and always return the same result for the same inputs.

The naming should start with `S`. Example: `STab.vue`.
