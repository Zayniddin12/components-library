# CSS

## **What is CSS? (CSS o’zi nima?)**

```CSS

## What is CSS? (CSS o’zi nima?)

**CSS** - Cascading Style Sheets ( Kaskadli dizaynlar jadvallari)

CSS describes the visual style and presentation of the content
written in HTML (HTML-da yozilgan kontentga dizayn qo’shib beradi.)

CSS consists of countless properties that developers use to format the content: properties about font, text, spacing, layout, etc. (CSS formatlash uchun foydalanadigan son-sanoqsiz xususiyatlardan iborat: shrift, matn, interval, tartib va boshqalar haqida xususiyatlar.)

```

## **Internal Style)**

```CSS

<head>
    <meta charset="UTF-8" />
    <title>The Basic Language of the Web: HTML</title>
    <style>
      h1 {
        color: blueviolet;
      }
    </style>
</head>

Internal Style har doim <head> tagi ichida <style> tagi ochib uning ichiga biror bir tagni tanlab unga dizayn berish mumkin.

```

## **External Style**

```CSS

h1 {
  color: aqua;
  font-size: 100px;
}

Birinchi navbatda biz CSS dizayn uchun alohida fayl ochamiz. Masalan Style.css keyin uning ichiga mana shu kodni yozamiz. Keyinchalik biz HTML faylga CSS ni tanishtirishimiz kerak. Buning <head> tagi ichiga <link href=”style.css”> dib yozishimiz kerak.


// index.html
<!DOCTYPE html>
<html lang="en">
  <head>
    <meta charset="UTF-8" />
    <meta http-equiv="X-UA-Compatible" content="IE=edge" />
    <meta name="viewport" content="width=device-width, initial-scale=1.0" />
    <title>Document</title>
    <link rel="stylesheet" href="style.css" />
    <!-- External style -->
    <style>
      h2 {
        background-color: aquamarine;
      }
    </style>
  </head>
  <body>
    <h1 style="color: red">Hello world</h1>
    <!-- Inline style -->
    <h2>Internal Style</h2>
    <!-- Internal style -->
    <p>External Style</p>
  </body>
</html>

// style.css
	p {
	  font-size: 50px;
	}

```
